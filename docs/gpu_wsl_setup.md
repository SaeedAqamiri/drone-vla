# فعال‌سازی GPU در WSL برای Gazebo / Isaac Sim

## وضعیت فعلی (اندازه‌گیری‌شده)

| مورد | مقدار | معنی |
|---|---|---|
| GPU | NVIDIA GeForce RTX 2080 (8 GB) | سخت‌افزار سالم و کافی |
| درایور ویندوز | **442.23** (CUDA 10.2، حدود ۲۰۲۰) | ❌ قدیمی‌تر از نیاز WSL |
| WSL | نسخهٔ **2** (هر دو توزیع) | ✅ درست |
| `/dev/dxg` در WSL | موجود | ✅ لایهٔ مجازی‌سازی آماده است |
| `nvidia-smi` در WSL | نصب نیست | ❌ چون درایور ویندوز آن را mount نمی‌کند |
| رندر Gazebo | `llvmpipe` (نرم‌افزاری) | ❌ GPU استفاده نمی‌شود |

نتیجه: **تنها مانع، درایور ویندوز است.** پشتیبانی GPU در WSL2 از درایور
ویندوز ۴۷۰ به بالا شروع می‌شود؛ ۴۴۲ خیلی قدیمی است.

## مراحل (به ترتیب)

### ۱) به‌روزرسانی درایور در ویندوز

1. از سایت رسمی NVIDIA برای **GeForce RTX 2080** آخرین درایور را دانلود کنید:
   - Game Ready یا Studio — فرقی برای این کار نمی‌کند.
   - نسخهٔ پیشنهادی: هر شاخهٔ ۵۵۰ یا بالاتر.
2. هنگام نصب گزینهٔ **Custom (Advanced)** را بزنید و مطمئن شوید
   **"Perform a clean installation"** تیک دارد.
3. **ری‌استارت کنید.** بدون ری‌استارت، WSL درایور جدید را نمی‌بیند.

> نکته: اگر لپ‌تاپ است، درایور مخصوص سازنده را ترجیح دهید. RTX 2080 روی
> دسکتاپ است، پس درایور عمومی NVIDIA درست است.

### ۲) بررسی بعد از ری‌استارت

در PowerShell:

```powershell
nvidia-smi
```

باید `Driver Version` بزرگ‌تر از ۴۷۰ باشد (مثلاً `5xx.xx`).

### ۳) بررسی در WSL

```bash
wsl -d Ubuntu-24.04 -u root -- bash -c "/usr/lib/wsl/lib/nvidia-smi; glxinfo -B | head -6"
```

باید این‌ها را ببینید:

- `/usr/lib/wsl/lib/nvidia-smi` کار کند و نام GPU را نشان دهد،
- `OpenGL renderer string` دیگر `llvmpipe` نباشد و چیزی مثل
  `D3D12 (NVIDIA GeForce RTX 2080)` باشد.

### ۴) چه چیزی نصب **نکنید**

- در WSL هیچ `nvidia-driver-*` یا `cuda-toolkit` مخصوص لینوکس نصب نکنید.
  درایور از ویندوز می‌آید و نصب درایور لینوکسی باعث خرابی می‌شود.
- فقط اگر بعداً Isaac Sim خواست، بستهٔ `cuda-toolkit` **از مخزن NVIDIA**
  لازم می‌شود، نه درایور.

## تأثیرش روی این پروژه

- **الان لازم نیست.** دنیای `field` با `RTF = 1.0` اجرا می‌شود؛ حتی با
  llvmpipe هم اپیزودها سر وقت ساخته می‌شوند.
- **بعداً لازم می‌شود** برای:
  - Isaac Sim (که بدون GPU بالا نمی‌آید)،
  - رندر دنیاهای سنگین‌تر (مثل baylands که با llvmpipe روی `0.22×` بود)،
  - آموزش شبکه روی GPU (torch فعلاً CPU است).
